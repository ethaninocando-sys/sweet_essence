# Image assets

The home page references the files below. Until the real photography is
dropped in here, each frame falls back to a warm honey-gradient backing
(see `src/components/ui/AssetImage.tsx`), so the layout always reads as
intentional.

Drop matching PNGs (or update the paths in `src/lib/content.ts` and the
direction components) using these names:

| File                    | Used by                                   |
| ----------------------- | ----------------------------------------- |
| `gen-hero.png`          | Hero jar — Editorial (D1) & Bold (D3)      |
| `gen-texture.png`       | Organic (D2) hero band, Bold (D3) parallax |
| `gen-apiary.png`        | Organic (D2) family-farm story            |
| `gen-wildflower.png`    | Product — Wildflower                       |
| `gen-mesquite.png`      | Product — Mesquite Reserve                 |
| `gen-citrus.png`        | Product — Citrus Blossom                   |
| `gen-darkbold.png`      | Product — Dark & Bold                      |
| `gen-soap.png`          | Product — Honeycomb Soap                   |
| `gen-candle.png`        | Product — Pure Honey Candle                |

Recommended: roughly 3:4 (product/hero) and 16:9 (texture/apiary) crops,
web-optimized (~1200px longest edge).
